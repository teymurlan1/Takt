# Takt 15.0 — итоги релиза

Версия: 15.0.0 (`package.json`, `/api/health`). Кэш статики: `?v=150`. Включает всё из 14.0 (см. `docs/takt-14.0-release.md`).

## Новое в 15.0
- **Клиент.** Ближайшая запись крупной карточкой вверху «Мои записи»: время, «через N ч», услуга, специалист; кнопки «Маршрут», «Позвонить», «В календарь», «Повторить запись» (если специалист и услуга доступны), «Изменить» (перенос и отмена — через существующее меню записи, два тапа). Звёзды отзыва — крупные нажимаемые (44 px), подсветка слева направо.
- **Настройки уведомлений клиента** (Профиль): напоминание за 24 часа, за 2 часа, просьба об отзыве, «пора записаться снова», лист ожидания. Выключенные типы не отправляются (проверка на сервере в очереди доставки). Подтверждения записи и сообщения об отмене/переносе приходят всегда.
- **Главный экран специалиста — «Требует внимания»:** ждут подтверждения, скорый визит без ответа клиента, риск неявки (клиент с ≥2 неявками), давно не приходили, лист ожидания, подписка (≤7 дней / льготные дни / закончилась), прогресс чеклиста, свободные окна сегодня, записи на 24 часа. Один запрос к серверу.
- **Бот.** Меню команд локализовано (ru, kk, az, uz).
- Записи клиента теперь содержат адрес и телефон специалиста (для маршрута и звонка).

## Миграции (только добавляющие)
`0013`–`0017`. Нужно выполнить `npm run db:remote` (схема также создаётся автоматически при первом запросе).

## Действия после загрузки
1. `npm install`, `npm test` (нужен `happy-dom` для `test/v12.test.mjs`).
2. `npm run db:remote`.
3. В админке «Подключить бота» — обновит меню команд для всех языков (теперь 4 вызова `setMyCommands`). Вебхук менять не нужно.
4. Проверить на телефоне (светлая и тёмная темы): «Мои записи», Профиль, главный экран специалиста, Подписка, Профиль → Инструменты, админ-разделы.
5. Включение паузы записей после окончания подписки — `POST /api/v140/admin/billing {"enforce":true}` (по умолчанию выключено).

## Что уже было в проекте (проверено, не переписывалось)
Админ-аналитика (специалисты, активные, удержание 7/30, воронка, конверсия триала), рассылки с предпросмотром, фильтрами (язык, статус подписки, дата регистрации, «скоро конец подписки») и очередью (через outbox, 3 сообщения в минуту), настройки уведомлений специалиста, напоминания клиенту за 24 и 2 часа с кнопками, просьба об отзыве, .ics/Google Календарь, отчёты по неявкам.

## Не сделано — на следующий релиз
- Онлайн-оплата (архитектура готова).
- Депозит/предоплата, буфер между записями и допуслуги, «горящие окна».
- Расписание: визуальные режимы день/неделя/месяц с исключениями и быстрым переносом — в проекте есть календарь и исключения, но экран не переработан.
- Админка: сегменты рассылок «по тарифу» как отдельный фильтр с названием тарифа (сейчас по статусу подписки), график оттока, включение/выключение отдельных сообщений бота.
- Фото портфолио в D1 (base64); при росте — Cloudflare R2.
- Нестабильные по времени суток тесты `v4` («master one-hour reminder…») и `v5` («late bookings…») — были такими и до 14.0.
- Интерфейс проверялся только тестами в Node (без браузера): визуальную проверку на телефоне нужно сделать вручную.
