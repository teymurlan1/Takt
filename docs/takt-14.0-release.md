# Takt 14.0 — итоги релиза

Версия: 14.0.0 (`package.json`, `/api/health`). Кэш статики: `?v=140`.

## Что сделано
**Поддержка в боте.** Веб-форма отключена (API отвечает 410). Кнопка «Поддержка» открывает бота (`?start=support`) и закрывает Mini App. Команды `/support`, `/help`, `/cancel`. Обращение: номер, статус (новое / в работе / закрыто), язык, роль, подписка. Уходит OWNER и SUPPORT с кнопками «Ответить / В работу / Закрыть». Лимит 3 обращения в час. Ответ уходит пользователю на его языке.

**Подписка.** Состояния: активна / пробный / льготные дни (3) / закончилась. Экран: срок, что входит, что после окончания, «Связаться по оплате» (в чат бота), реферальный код и ввод кода, история платежей. Рефералы: оба получают по 7 дней (у приглашающего до 12 наград, код — в первые 14 дней). Таблица платежей и ручное продление админом (идемпотентно, с журналом). Напоминания об окончании за 7 / 3 / 1 день и в день окончания — один раз на получателя, с тихими часами (22:00–09:00 по поясу специалиста). Пауза новых записей после окончания реализована, но ВЫКЛЮЧЕНА по умолчанию (включается `POST /api/v140/admin/billing {"enforce":true}`).

**Уведомления.** Пауза между повторами растёт (×2, до суток, учитывается `retry_after`). Остальная очередь (идемпотентные ключи, блокировка бота, 24ч/2ч, итоги дня) была в проекте и не менялась. Админ-экран «Не доставлено» с причинами.

**Админка.** «Поддержка» — обращения с фильтрами и ответом; «Не доставлено»; «Бот» — тексты `/help` (специалист, клиент), первое приветствие, приглашение в поддержку: по языкам, предпросмотр, версии, откат, журнал.

**Кабинет специалиста → «Инструменты»** (Профиль → Инструменты): чеклист старта; клиенты с визитами, неявками, «давно не приходил», тегами, днями рождения, чёрным списком и кнопкой «Вернуть» (шаблоны, 1 сообщение в неделю на клиента, не более 20 в сутки); шаблоны сообщений; отзывы с ответом специалиста; портфолио (20 фото, до 30 настройкой, сжатие на устройстве ~80 КБ); экспорт клиентов и записей в CSV.

**Клиент.** Лист ожидания (кнопка при отсутствии свободного времени; уведомление при освобождении окна, проверка раз в 5 минут); напоминание «пора записаться снова» (по среднему интервалу визитов, один раз на последний визит); галерея работ и подвал «Создать такую же страницу» на странице специалиста. Клиент из чёрного списка не может записаться.

Языки: ru, kk, az, uz для всех новых экранов и сообщений бота.

## Миграции (только добавляющие)
`0013` поддержка, `0014` платежи/рефералы/напоминания, `0015` инструменты, `0016` тексты бота. Нужно выполнить: `npm run db:remote`. Схема также создаётся автоматически при первом запросе.

## Действия после загрузки
1. `npm install` (нужен `happy-dom` для `test/v12.test.mjs`), `npm test`.
2. `npm run db:remote`.
3. В админке нажать «Подключить бота» (обновит меню команд). Вебхук менять не нужно.
4. Проверить на телефоне в светлой и тёмной темах: Подписка, Профиль → Инструменты, страница специалиста, админ-разделы.
5. Когда будете готовы — включить паузу записей после окончания подписки (см. выше).

## Известные ограничения / на следующий релиз
- Описания команд бота локализованы не по языкам (одно описание на русском).
- Онлайн-оплата не подключена (архитектура готова: `payments`, статусы, ручное продление).
- Настройки уведомлений клиента (отдельные переключатели) и расширенные тихие часы для остальных типов сообщений.
- Админка: рассылки по группам с очередью и лимитом скорости (есть базовые рассылки с предпросмотром), воронка «открыл → услуга → время → записался», конверсия триала, отток, включение/выключение отдельных сообщений бота.
- Кабинеты: переработанный главный экран, расписание день/неделя/месяц с исключениями, быстрый перенос, «давно не приходил» как отдельный список, «Ближайшая запись крупно» у клиента, интерактивные звёзды отзыва.
- Депозит/предоплата, буфер между записями и допы, «горящие окна».
- Фото портфолио хранятся в D1 (base64); при росте — перенос в Cloudflare R2.
- Тесты `v4` (№ «master one-hour reminder…») и `v5` («late bookings…») зависят от времени суток и нестабильны и в исходной версии.
