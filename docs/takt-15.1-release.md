# Takt 15.1.0 — стабилизация

Миграций нет: `npm run db:remote` не нужен. Команды бота переустанавливать не нужно. Оплату и паузу записей не трогали (пауза выключена).

## Что изменено
- Тесты v4 и v5 больше не зависят от времени суток (фиксированные часы, `scripts/fake-clock.mjs`). Причина падений: запись не может переходить через местную полночь, а тесты ставили её на «сейчас + 20 мин / 1 ч».
- Кэш: все подключения файлов и внутренние импорты на `?v=151` (раньше часть застряла на `?v=120`).
- Карточка ближайшей записи у клиента обновляется после переноса/отмены и пересчитывает «через N ч».
- При сбое сети блоки «Требует внимания» и настройки уведомлений показывают «Повторить», а не исчезают.
- Календарь: выходной на целый день больше не показывается на следующий день (`public/schedule151.js`).
- Новые тесты `test/v151.test.mjs`: матрица ролей, приватность клиента, кэш, календарь, цепочка запись → напоминание → перенос → отмена → завершение → отзыв.

## Не проверено (нет браузера, телефона, живого бота)
Внешний вид и поведение интерфейса: тёмная тема, маленькие экраны, safe-area, медленная сеть, двойные нажатия.
